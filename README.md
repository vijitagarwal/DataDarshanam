# dataदर्शनम् (DataDarshanam) 📊

### Conversational AI for Instant Business Intelligence & Dashboards

> **Natural Language → Interactive Visualizations → AI Business Insights. Instantly.**

---

## 🌟 Overview

**dataदर्शनम्** is a modern, full-stack Conversational Business Intelligence (BI) platform that enables executives, managers, and data analysts to query complex datasets using plain English.

Instead of writing SQL queries or building static charts in legacy BI tools, users simply ask questions in natural language and receive:
1. **Interactive Charts**: Bar, Line, Pie, Scatter, and Area charts with live chart-type switcher pills.
2. **KPI Summary Cards**: Real-time aggregation of Total, Average per Group, Top Performer, and Peak Value.
3. **AI Business Insights**: Concise 2–3 sentence executive takeaways generated by Groq.
4. **Dataset Schema Profiler**: Auto-detection of metrics, dimensions, date fields, row counts, and custom CSV uploads.

## ✨ Features

- **💬 Natural Language Querying**: Query sales, revenue, categories, dates, and regions without writing any code or SQL.
- **🔄 Live Chart-Type Switcher**: Toggle between `Auto`, `Bar`, `Line`, `Pie`, `Scatter`, and `Area` visualizations instantly without re-querying the database.
- **📊 3-Chart Dashboard Overview**: One-click generation of a comprehensive multi-chart business dashboard.
- **🔗 Multi-Turn Conversation Memory**: Maintains context from prior questions (e.g., asking follow-up questions about a specific category or timeframe).
- **📌 Saved Insights & Export**: Pin important charts to the sidebar and export all saved insights into a styled HTML report.
- **📥 CSV Data Export & Upload**: Download query results as CSV files or upload your own dataset.

### Frontend
- **Framework**: Next.js 16 (App Router), React 19

## 🚀 Running Locally

### Environment configuration

Create `backend/.env` for local development. Keep secrets out of source control.

```env
GROQ_API_KEY=your-groq-api-key
GROQ_MODEL=openai/gpt-oss-120b
ALLOWED_ORIGINS=http://localhost:3000
MAX_UPLOAD_BYTES=26214400
MAX_UPLOAD_ROWS=250000
MAX_UPLOAD_COLUMNS=100
```

For a deployed frontend, set `NEXT_PUBLIC_API_URL` to the public backend URL before building.
Each browser profile receives a workspace identifier stored locally, so uploaded datasets are isolated from other browser sessions. This is session/workspace isolation, not user authentication; add authentication before treating it as a multi-tenant service.

### 1. Start FastAPI Backend
```bash
cd backend
python -m venv venv
# Activate venv
pip install -r requirements.txt
python -m uvicorn main:app --reload --port 8000
```

### 2. Start Next.js Frontend
```bash
cd frontend
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
